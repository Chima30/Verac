## Caveats
* Steps were run from shell commands, not yet from the web app or an automated pipeline.
* The "agent" is a throwaway key; there is no AI decision involved in these payments yet.
* The revert reasons come from replaying the failed transactions with `cast run`.
* Not demonstrated yet: human approval flow (`approvePayment`) followed by a payment, escrow funding, classical-key-only theft attempt against a closed window.
